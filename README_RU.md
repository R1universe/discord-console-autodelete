# Discord AutoDelete — автоудаление сообщений Discord по таймеру

**Экспериментальный JavaScript-скрипт для Discord Web:** позволяет настроить попытку автоматического удаления **своих новых сообщений** через заданное время. Для личных сообщений и серверных каналов доступны отдельные таймеры.

> [!WARNING]
> **Discord запрещает self-bot — автоматизацию обычного пользовательского аккаунта.** Использование может привести к ограничению или блокировке. Это **не официальный инструмент Discord**, а экспериментальный прототип. Удаление сообщений не гарантируется.

## Возможности

- Независимые задержки удаления в **DM** (включая групповые) и **серверных каналах** — от **1 секунды до 24 часов**.
- Быстрые пресеты **4s** и **60s**, ручной ввод числа секунд.
- Кнопки **Everywhere / Servers / DMs**; при выборе одного типа отображается только нужный таймер.
- Полупрозрачный интерфейс Apple × Discord: синеватый в выключенном состоянии и зелёный при включении.
- **Enable / Disable**, три показателя — **Queued / Requests / Errors**, журнал **Diagnostics**.
- Кнопка **−** полностью прячет окно, но **не останавливает** включённый скрипт. Для возврата: `DiscordAutoDelete.open()`.
- Настройки задержек сохраняются локально, но после перезагрузки Discord Web мониторинг **не включается автоматически**.

## Как запустить

1. Прочитай [`autodelete.js`](./autodelete.js). Никогда не вставляй неизвестный код в консоль авторизованного аккаунта.
2. Открой [Discord Web](https://discord.com/app) и консоль разработчика: macOS Chrome — `Cmd + Option + J`; Windows/Linux — `Ctrl + Shift + J`.
3. Скопируй **проверенный исходный код**, вставь в консоль и выполни.
4. Выбери **Where to delete**, задержки для DM и серверов, нажми **Enable**.
5. Чтобы остановить работу и отменить все ожидающие удаления, нажми **Disable**. Для полного завершения нажми **×**.

Никогда не передавай токен аккаунта, cookies или заголовки авторизации. Не запускай загрузчики вида `fetch(...).then(eval)` из непроверенных источников.

### Команды управления

```js
DiscordAutoDelete.status()          // Текущее состояние
DiscordAutoDelete.setDmDelay(4)      // Задержка DM (секунды)
DiscordAutoDelete.setServerDelay(60) // Задержка серверов
DiscordAutoDelete.setScope("all")    // "all", "servers", "dm"
DiscordAutoDelete.open()             // Вернуть полностью скрытую панель
DiscordAutoDelete.openDiagnostics()  // Открыть журнал
DiscordAutoDelete.pause()            // Остановить и отменить очередь
DiscordAutoDelete.stop()             // Завершить скрипт
```

## Что означают счётчики

| Счётчик | Значение |
| --- | --- |
| **Queued** | Сообщения с ожидающими таймерами |
| **Requests** | Число вызовов удаления — **не** число подтверждённых удалений |
| **Errors** | Перехваченные ошибки — некоторые фоновые HTTP-ошибки могут не попасть сюда |

Таймер отсчитывается **с момента, когда скрипт увидел подтверждённое сообщение**, а не обязательно с момента нажатия Send. Настройка `1 секунда` не гарантирует удаление точно за секунду. Другие люди могут прочитать или сохранить сообщение до удаления.

## Ограничения и безопасность

- [Правила Discord относительно self-bot](https://support.discord.com/hc/en-us/articles/115002192352-Automated-User-Accounts-Self-Bots) прямо запрещают автоматизацию обычного аккаунта.
- Скрипт зависит от **недокументированных внутренних модулей Discord**, которые могут измениться и перестать работать.
- Текущий исходник не требует ввода токена и не сохраняет текст сообщений, но запуск JavaScript в авторизованной вкладке сам по себе чувствителен с точки зрения безопасности.
- Кнопка **−** только скрывает интерфейс. **Disable** останавливает мониторинг и отменяет очередь; обновление страницы также останавливает запущенный скрипт.
