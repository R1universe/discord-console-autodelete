# Discord AutoDelete v2

Экспериментальная панель автоматического удаления сообщений для **Discord Web**.

> **Внимание:** проект использует недокументированные внутренние функции Discord. Self-bot-автоматизация обычного аккаунта противоречит правилам Discord и может привести к блокировке. **Работа на текущей версии Discord не подтверждена реальным запуском.** Прежде чем использовать код, проверьте его самостоятельно.

## Что нового в v2

- Панель управления прямо поверх Discord: **не нужно переписывать код для изменения настроек**.
- Поиск модулей по именованным и обычным экспортам (раньше искались только основные экспорты и `default`).
- Выбор основного Webpack-runtime по размеру кэша (некоторые сборки имеют несколько runtime).
- Таймер: вручную от 2 секунд до 24 часов, пресеты **5 / 10 / 30 / 60 секунд**.
- Область: **везде / только серверы / только DM** (для фильтрации используется обнаруженный тип канала).
- Кнопки **Включить**, **Пауза**, **Повторить подключение**, **Свернуть**, **Закрыть**.
- Видимые ошибки, журнал без содержания сообщений, счётчики ожидающих удалений и вызовов удаления.
- Задержка и область сохраняются локально в браузере (`localStorage`). Состояние **«включено» не сохраняется**: после повторного запуска требуется включить удаление вручную.
- Секреты, токены и текст сообщений **не извлекаются и не записываются в файлы**; отдельные сетевые запросы скрипт не делает. Внутренний метод Discord `deleteMessage`, конечно, обращается к серверам Discord.

## Установка в браузере

1. Прочитайте исходный код [autodelete.js](./autodelete.js) **целиком**. Никогда не запускайте в консоли непроверенный JavaScript.
2. Войдите в нужный аккаунт на https://discord.com/app.
3. Откройте **DevTools → Console**: macOS Chrome — `Cmd + Option + J`, Windows/Linux — `Ctrl + Shift + J`.
4. Скопируйте содержимое файла `autodelete.js` и вставьте в консоль. Не используйте `fetch(...).then(eval)` и другие удалённые загрузчики.
5. Если всё совместимо, появится панель и индикатор **ПАУЗА**. Сначала выберите задержку и область, затем нажмите **«Включить автоудаление»**.
6. Отправьте безобидное тестовое сообщение и убедитесь, что оно исчезло после задержки. Счётчик «Запросов» означает попытки вызова внутреннего действия, **а не подтверждённое сервером удаление**.

Если появится ошибка вида `FluxDispatcher: 0 вариантов`, внутренний API всё ещё отличается от ожидаемого — **скрипт не подключился**, поэтому ничего автоматически не удаляет. Не ищите токен и не вставляйте его куда-либо для исправления этой проблемы. Можно нажать «Повторить подключение» или предоставить текст ошибки разработчику.

## Управление из панели

- **5s / 10s / 30s / 60s** — быстрый выбор задержки.
- **Поле секунд** — любое целое значение от 2 до 86400.
- **Где удалять** — «Везде», «Только серверы», «Только DM».
- **Включить** — начинает отслеживание новых сообщений.
- **Пауза** — останавливает новые удаления **и отменяет всю ожидающую очередь**.
- **Диагностика ↻** — заново ищет модули; тоже сбрасывает очередь.
- **−** — сворачивает панель до небольшой кнопки.
- **×** — полностью останавливает скрипт и убирает интерфейс.
- Заголовок панели можно перетаскивать мышью.

Новые настройки задержки и области относятся только к **новым сообщениям**: существующие таймеры не пересчитываются.

## Команды в консоли (необязательны)

```js
DiscordAutoDelete.status()       // посмотреть состояние
DiscordAutoDelete.open()         // развернуть панель
DiscordAutoDelete.hide()         // свернуть панель
DiscordAutoDelete.setDelay(30)   // установить 30 секунд
DiscordAutoDelete.setScope("dm") // all | servers | dm
DiscordAutoDelete.resume()       // включить
DiscordAutoDelete.pause()        // пауза и отмена очереди
DiscordAutoDelete.retry()        // переподключение
DiscordAutoDelete.stop()         // остановить и убрать панель
```

## Что скрипт не умеет

- Не удаляет старую переписку; отслеживает только события после запуска.
- Не гарантирует работу после обновлений Discord, перезагрузки страницы, закрытия вкладки, ограничения API или смены аккаунта.
- Не восстанавливает очередь после перезагрузки вкладки. Сохраняются только настройки, не тексты, токены и не ожидающие ID.
- Не умеет отслеживать новые сообщения, если вкладка не получает соответствующее событие.
- Не гарантирует приватности: уведомления, архивирующие боты, сторонние клиенты и скриншоты могут сохранить текст до удаления.
- Если клиент не позволяет определить канал, фильтр «Только серверы / DM» может пропустить часть сообщений вместо предположительного удаления.
- Нельзя считать отсутствие ошибок подтверждением удаления на стороне Discord.

## Техническое объяснение ошибки v1

В прежней версии код просматривал только объект `exports` и `exports.default` и требовал узкий набор признаков `FluxDispatcher`. У Discord бывают **именованные экспорты** и несколько Webpack-runtime. В v2 код перебирает именованные экспорты и выбирает runtime с более крупным кэшем; при неоднозначном результате он по-прежнему прекращает подключение, не угадывая модуль.

Это возможное исправление показанной ошибки, а **не обещание совместимости** с любой сборкой Discord.

## Безопасность и источники

- **Не публикуйте токены** или скриншоты с заголовками авторизации.
- Вставляйте только проверенный код, который вам понятен. Не запускайте его через сторонние «one-click loaders».
