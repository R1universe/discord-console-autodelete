# Discord AutoDelete — JavaScript для консоли браузера

Экспериментальный скрипт: отслеживает **только новые сообщения текущего пользователя** в открытой веб-сессии Discord и через установленную задержку вызывает внутреннее действие удаления сообщения. Рассчитан на серверные каналы и DM, события о которых видит веб-клиент.

> **Предупреждение.** Это неофициальная автоматизация обычного аккаунта (self-bot). Discord запрещает self-bots и модификации клиента; возможна блокировка аккаунта. Из-за изменений в Discord скрипт может не запуститься или не удалить сообщение. Не используйте для информации, которая не должна быть сохранена кем-то ещё.

## Что делает

- По умолчанию задержка **10 секунд** (можно изменить в исходнике).
- Реагирует на внутренние события `MESSAGE_CREATE` только при `author.id === ID вашего аккаунта`.
- Работает с сообщениями сервера, DM и групповыми DM, если веб-клиент получает эти события.
- Использует внутренний метод клиента `deleteMessage(channelId, messageId)`.
- Не читает токен, не просит пароль, не читает/сохраняет содержимое сообщений, не вызывает внешние сайты.
- Не удаляет старую переписку, не пытается восстановить сообщения, отправленные, пока скрипт не работал.

## Установка

1. **Прочитайте `autodelete.js` перед запуском.** Никогда не вставляйте непроверенный код в консоль сайта: чужой JavaScript может украсть вашу сессию.
2. Откройте `https://discord.com/app` в браузере, войдите в нужный аккаунт.
3. Откройте DevTools (на Mac: `Option + Cmd + J` в Chrome; в Windows/Linux: `Ctrl + Shift + J`).
4. Скопируйте **весь файл `autodelete.js`** в Console и выполните. Если браузер блокирует вставку, прочитайте предупреждение браузера и не обходите защиту вслепую.
5. Убедитесь, что консоль пишет `EXPERIMENTAL. Running...`. Если появляется `Unsupported Discord build`, код отказался работать из-за изменения внутреннего API — ничего не удалено.
6. Проверьте на безобидном тестовом сообщении, что происходит через 10 секунд. Это не проверялось в реальном аккаунте Discord.

## Управление

В той же вкладке в Console:

```js
DiscordAutoDelete.status()       // состояние и число заданий
DiscordAutoDelete.setDelay(30)   // 30 секунд для НОВЫХ сообщений
DiscordAutoDelete.stop()         // остановить; отменить отложенные удаления
```

Чтобы поменять задержку по умолчанию, отредактируйте строку `const DEFAULT_SECONDS = 10;` в `autodelete.js`.

## Важные ограничения

- **Нет гарантий удаления.** Сеть, права, обновления клиента, rate limits и сбои могут помешать удалению или задержать его. Счётчик успешных запросов не гарантирует окончательное удаление на сервере.
- **Не работает после закрытия/перезагрузки страницы.** Очередь хранится только в памяти текущей вкладки и не сохраняется.
- **Не работает в мобильном Discord или в других вкладках, куда скрипт не вставлялся.** Может удалить сообщение, отправленное с другого устройства, только если текущая вкладка получила событие.
- **Только сообщения, отправленные после запуска.**
- **Код зависит от приватных модулей Discord.** Webpack exports и события могут изменяться; при неоднозначности код прекращает запуск вместо случайного вызова чужого метода.
- Discord Recall, модераторские боты, уведомления, скриншоты и другие архивы могут сохранить сообщение до удаления.

## Тесты

`node test/test.js` — локальный тест с имитацией API Discord, **без подключения к аккаунту**. Тестирует задержку, фильтр автора и остановку. Не подтверждает, что код работает в текущем Discord.
